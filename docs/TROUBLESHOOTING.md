# Troubleshooting

- `java` not found: install Java 21 and reopen PowerShell.
- Unsupported Java: confirm the jar is Minecraft 1.21.11, not Paper 26.x.
- Missing addon: place it in `plugins/BentoBox/addons`, fully restart, and run `/bentobox version`.
- Web unavailable from another device: verify the trusted LAN, `0.0.0.0` binding, and Private-profile TCP 3000.
- Never use `/reload`; stop cleanly and restart.
